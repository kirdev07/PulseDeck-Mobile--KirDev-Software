# Соответствие Android-клиента и сервера PulseDeck (Windows)

## Обозначения

**Статусы:**
- ✅ — есть на сервере и будет в клиенте.
- ⚠️ — частично.
- ❌ — нет на сервере: кнопку не показываем, пока сервер не доработают.

**Транспорт:** все запросы через TLS 8767 `/api/v1/...` с пиннингом сертификата, токен `Authorization: Bearer`. Живые данные идут по WebSocket `/api/v1/display`. Открытый HTTP v0 не используем.

## Доработки сервера (сделано, 2026-10-26)

1. Аптайм и нагрузка по ядрам в `metrics`.
2. Процессы: список с CPU и памятью, завершение. Системные процессы и сам PulseDeck защищены.
3. Файлы: создание папки, переименование, удаление в корзину. Нельзя трогать корень диска и относительные пути.
4. Права телефона: «полный» или «только просмотр». «Только просмотр» — это показатели и музыка, без команд, файлов и скриншотов (403). Права меняются на ПК, экран «Телефон». Старые телефоны сохраняют полный доступ.

## Осталось без поддержки сервера

- **Температуры.** Нужен драйвер датчиков, например LibreHardwareMonitor. Это отдельное решение.
- **Терминал.** Не делаем.
- **Shuffle/repeat, устройство вывода.** Windows Media Session API даёт shuffle/repeat не для всех плееров. Возможно позже.
- **Список установленных программ, выход из системы, запись экрана.**
- **События по WebSocket.** Сейчас события приходят опросом раз в 10 с, только пока открыт экран.

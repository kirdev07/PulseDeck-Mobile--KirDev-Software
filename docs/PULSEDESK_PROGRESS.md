## Найдено и исправлено на телефоне

- Соединение не стартовало после сопряжения (гонка `job` на `Main.immediate`).
- Альбомная ориентация: контент под системными кнопками; вкладки и мини-плеер занимали полэкрана. Теперь вкладки — боковая панель.
- Плеер в альбомной ориентации: обложка закрывала кнопки.
- Список окон перескакивал после каждого действия.
- «System Idle Process» с 81% в начале списка процессов; кнопка «Завершить» у системных процессов.
- Переименование: курсор в начале; теперь старое имя выделено.
- Скриншот был мелким; теперь на весь экран.

## Не сделано намеренно

- **Терминал** — опасно.
- **Температуры** — Windows не отдаёт их без драйвера.
- **Shuffle/repeat, устройство вывода, «лайк»** — нет API на ПК.
- **Список установленных программ** — нет API на ПК.
- **Выход из системы, запись экрана** — нет API на ПК.
- **QR-сопряжение** — выключено по решению владельца.

## Известные ограничения

- В фоне без трека связь закрыта. Если музыка запустится на ПК, пока приложение свёрнуто, карточка появится при следующем открытии: Android не даёт стартовать службу из фона.
- Отправка файлов с телефона идёт только в папку загрузок PulseDeck на ПК — так устроен сервер.
- Кнопки в медиакарточке используют системные иконки Android.

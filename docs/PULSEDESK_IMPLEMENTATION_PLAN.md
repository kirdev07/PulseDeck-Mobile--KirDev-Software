# План работ PulseDesk Android

Проект: `PulseDeck-MobileAPP`, пакет `com.kirdev.pulsedeckmobile`. Название в интерфейсе: **PulseDesk**.

## Основа

Не переписывать с нуля. Взять проверенный на телефоне сетевой слой из PulseDeck Panel:
- `PinnedTls`, `PairingClient`, `Discovery`, `PanelConnection` (WebSocket, USB, переподключение);
- `PairingStore` (Keystore, несколько ПК), `Protocol`.

Логику функций (файлы, программы, окна, питание, скриншот, события) перенести из старого клиента. Транспорт сменить на TLS v1, UI — на Compose.

## Этапы

| Этап | Что | Результат |
|---|---|---|
| **B. Музыка** | Медиа только из WS `media`, без опроса. Состояния PLAYING/PAUSED/STOPPED/IDLE/DISCONNECTED. MediaSession и уведомление только при playing/paused, при IDLE снимаются. Сервис соединения отдельно от медиа. Обложка один раз на ключ, уменьшенная. Remote-громкость только при playing | Модуль медиа и тесты состояний |
| **C. Каркас** | Compose + M3, Navigation, MVVM/StateFlow, пакеты `core/designsystem/connection/dashboard/monitoring/media/remote/files/applications/terminal/notifications/settings`. Сетевой слой из Panel. Хранилище с шифрованием | Пустые экраны, навигация, тема |
| **D1** | Splash (волна KiroX), Подключение (поиск, IP, код, USB), Устройства | Сопряжение работает |
| **D2** | Главная: CPU, GPU, RAM, сеть, диски, мини-плеер, события. Мониторинг: графики из потока | Реальные метрики |
| **D3** | Музыка (полный плеер), медиакарточка Android | |
| **D4** | Управление: питание с подтверждением и таймером, сон, блок, громкость, окна, программы, сценарии, сайт, скриншот | |
| **D5** | Файлы: навигация, скачать, отправить, история, прогресс | |
| **D6** | Уведомления (события ПК), Настройки, Оформление (AMOLED/Graphite, акцент, анимации) | |
| **E** | Подключение экранов к API, обработка 401/423/потери связи | |
| **F** | Сборка, lint, тесты, проверка на телефоне — только с разрешения на установку | |

## Экраны, которых не будет

Пока сервер не доработан, этих экранов и кнопок в приложении нет:
- Терминал;
- Приложения/процессы;
- температуры;
- нагрузка по ядрам;
- shuffle/repeat;
- выбор устройства вывода;
- «Выход из системы»;
- запись экрана;
- создание, переименование и удаление файлов.

В меню на их месте ничего не будет — не заглушки «скоро». Список доработок сервера — в `PULSEDESK_API_COMPATIBILITY.md`.
